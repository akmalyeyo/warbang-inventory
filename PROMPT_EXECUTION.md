# Prompt Execution — Eksekusi Awal

Baca `AGENTS.md` dan `docs/SOT.md` terlebih dahulu. Keduanya adalah kontrak proyek dan Single Source of Truth.

Lanjutkan implementasi front-end **Pengelolaan Persediaan dan Pelaporan Stok Barang Berbasis Web pada Toko Warbang** dengan React + Vite + TailwindCSS.

1. Audit struktur dan kesesuaian implementasi dengan SOT.
2. Pastikan tujuh modul tersedia: Login & Hak Akses, Data Barang & Kategori, Barang Masuk, Barang Keluar, Monitoring Stok, Laporan Persediaan, Dashboard.
3. Gunakan data dummy lokal; jangan membuat backend, API, database, atau integrasi eksternal.
4. Pastikan barang masuk menambah stok; barang keluar mengurangi stok dan menolak stok negatif.
5. Pastikan dashboard, monitoring, dan laporan menggunakan sumber state yang sama.
6. Pastikan pencarian, filter, form, validasi, notifikasi, navigasi, dan ekspor CSV bekerja.
7. Jalankan `npm run build`, perbaiki error, lalu laporkan hasil.

Jangan menambah ruang lingkup, mengganti identitas/palet, atau mengklaim login demo sebagai keamanan produksi. Jika instruksi bertentangan dengan SOT, berhenti dan minta klarifikasi.

Laporan akhir wajib memuat status tiap modul, perilaku yang diuji, hasil build, batasan tersisa, dan langkah berikutnya yang masih berada dalam ruang lingkup.
